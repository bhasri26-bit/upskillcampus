# Diabetes Prediction using Machine Learning

## Project
A Data Science and Machine Learning project that predicts whether a person is likely to have diabetes using the Pima Indians Diabetes Dataset.

## Model
Logistic Regression

## Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook / VS Code

## Main Steps
1. Load the dataset
2. Check and preprocess the data
3. Replace invalid zero values with median values
4. Split data into training and testing sets
5. Standardize the features
6. Train Logistic Regression
7. Evaluate the model
8. Predict diabetes for a sample patient
